# 🧠 Brain Teddy

> Personal second brain, knowledge base, and digital workspace.

---

## 📖 Overview

ยินดีต้อนรับสู่ **Brain Teddy** คลังบันทึกความรู้ ไอเดีย โปรเจกต์ และข้อมูลส่วนตัว (Second Brain / Personal Knowledge Base) สำหรับจัดระเบียบความคิดและเก็บรวบรวมองค์ความรู้ต่างๆ

## 📂 Proposed Structure (PARA Method)

```text
brain-teddy/
├── projects/      # สิ่งที่กำลังลงมือทำและมีเดดไลน์ชัดเจน
├── areas/         # ขอบเขตความรับผิดชอบและเรื่องที่ต้องดูแลต่อเนื่อง
├── resources/     # คลังความรู้ เอกสารอ้างอิง และหัวข้อที่สนใจ
├── archives/      # ข้อมูลหรือโปรเจกต์ที่เสร็จสิ้นแล้ว/ไม่ได้ใช้งาน
└── notes/         # บันทึกทั่วไป บันทึกด่วน (Inbox / Daily Notes)
```

## 🛠️ Tools & Workflow

- **Format:** Markdown (`.md`)
- **Compatibility:** Obsidian, VS Code, Antigravity IDE, หรือ Text Editor ทั่วไป
- **Version Control:** Git & GitHub

## 🚀 Getting Started

1. Clone repository:
   ```bash
   git clone https://github.com/SuperTeddy447/brain-teddy.git
   ```
2. เปิดโฟลเดอร์ใน Editor ที่ต้องการ เช่น VS Code หรือ Obsidian
3. เริ่มต้นจดบันทึกหรือจัดโครงสร้างข้อมูลตามความเหมาะสม
